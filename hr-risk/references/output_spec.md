# 출력 양식

## 퇴직위험_결과_YYYYMM.xlsx

`YYYYMM`은 **기준일이 속한 월**이다(기준일 2026-04-30 → `퇴직위험_결과_202604.xlsx`). 같은 이름의 파일이 있으면 덮어쓴다. 이름·사번은 어느 시트에도 없다.

| 시트 | 내용 |
|---|---|
| 요약 | 요약 3줄, 기준일·관찰 기간·대상 인원, 분석의 한계 |
| 개인결과 | 점수 높은 순. 열: 분석용 ID, 등급, 점수(0~100), 본부, 조직, 직군, 직급, 근속(년), 계산에 쓴 가중치 합, 신호별 점수 6개(`판단불가` 표시 가능), 판단불가 신호, 판단 근거, 추가 확인 사항, 참고(계약 만료 예정 등) |
| 조직결과 | 본부 전체와 조직별 인원, 평균 점수, 상/중/하/판단불가 인원, 가장 많은 신호. 5명 미만은 '표본 부족' |
| 검증 | 등급별 실제 결과, 신호별 반례, 기준일 이후 정보 제외 건수, 분석의 한계 |
| 산정기준 | 신호·가중치·계산 방식, 점수 환산, 등급 경계, 제외한 정보, 기준일 이후 정보 규칙 |
| 데이터점검 | 중단/경고/정보 목록과 건수 |

`개인결과` 점수 열 이름은 "점수(0~100, 우선 확인 순서)"이고, 표 아래에 "퇴사 확률이 아니며 유지 우선순위와 합치지 않는다"는 안내를 둔다. `산정기준` 시트에도 같은 설명이 있다.

등급 칸은 색으로 구분한다(상 붉은색, 중 노란색, 하 초록색, 판단불가 회색).

`개인결과`의 소속·직급은 HR이 대상자를 좁힐 수 있게 넣었다. 작은 조직에서는 소속·직급 조합만으로 개인이 짐작될 수 있으므로 결과 파일도 HR 안에서만 다루도록 안내한다.

## 요약 3줄 형식

1. 기준일, 대상 인원, 등급별 인원과 비율. 점수는 확인 순서 지표이며 퇴사 확률이 아니라는 문구.
2. 상 등급 비율이 가장 높은 조직(표본 부족 조직 제외)과 가장 많이 나타난 신호 두 가지(근속 구간 제외).
3. 상 등급부터 확인 시작(업무량 점검, 면담, 성장 기회 논의), 예측 성능을 확인할 수 없다는 한계(사건 수·기준일 수), 유지 우선순위는 HR이 따로 판단한다는 문구.

세 줄은 `요약` 시트와 콘솔 출력에 같은 문장으로 나온다. 줄 수를 늘리지 않는다.

## ID매핑_YYYYMM.xlsx

| 시트 | 열 |
|---|---|
| 매핑 | 분석용 ID, 사번 |

- 결과 파일과 **분리해 HR만 보관**한다. 결과 파일을 공유할 때 이 파일은 함께 보내지 않는다.
- 분석용 ID는 기준일을 씨앗으로 섞어 번호를 매긴다. 같은 입력·기준일이면 같은 ID이고, 다른 달에는 ID가 달라지므로 월별 추적에는 쓸 수 없다(개인 추적을 막는 의도).
- 기본 저장 위치는 결과 파일과 같은 폴더다. `-MappingDir`로 다른 폴더를 줄 수 있다. 같은 폴더에 두었다면 결과 파일을 공유하기 전에 매핑 파일을 옮기라고 사용자에게 알린다.
