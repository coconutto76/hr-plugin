# 입력 조건

입력 파일은 `인사데이터_샘플.xlsx`와 같은 구조의 엑셀이다. 시트마다 첫 행이 열 이름이고, 대부분의 시트가 `employee_id`로 연결된다.

## 시트 역할

| 시트 | 역할 | 없을 때 |
|---|---|---|
| `v_employees_current` | 기준일 재직자 명단(분석 대상), 소속·직급·입사일·연차·계약 정보 | **중단** |
| `v_attendance_monthly` | 월별 근태(`overtime_hours`) | **중단** |
| `hr_performance_reviews` | 평가 이력(`final_rating`, `finalized_at`, `status`) | **중단** |
| `hr_employees` | 입사 기록. 재직자 명단의 입사일과 교차 확인 | 경고, 교차 확인만 생략 |
| `hr_compensation_history` | 급여와 급여 밴드. 밴드 위치 신호 | 경고, 해당 신호 판단불가 |
| `hr_promotion_reviews` | 승진 심사 결과. 승진 보류 신호 | 경고, 해당 신호 판단불가 |
| `hr_personnel_actions` | 인사발령. **점수에 쓰지 않고** 기준일 이후 기록 제외 건수만 점검 | 경고 |
| `개요` | 기준일 확인용 (`항목`=`기준일`) | 없어도 됨 |
| `퇴사라벨` | 검증에만 사용 (`left`, `left_any_180d`, `observed_until`) | 검증 1~2를 생략하고 한계 문구에 "퇴사 이력 없음" 기재 |
| `hr_leave_requests`, `hr_training_enrollments`, `hr_oncall_shifts`, `hr_survey*` | 읽지 않음 (설문은 점수에서 제외) | 상관없음 |

필수 열은 `scripts/run_hr_risk.ps1` 앞부분의 `$core`, `$optional` 목록과 같다. 필수 시트의 열 이름이 바뀌면 **중단**한다. 일부 선택 시트의 열 이름이 바뀌면 그 시트를 읽지 않고 경고한다.

## 기준일

우선순위: `-BaseDate` 인자 → `v_employees_current.as_of`. `개요` 시트의 기준일과 `as_of`가 서로 다르거나 `as_of`가 한 날짜가 아니면 **중단**한다.

기준일이 월말이면 그 달 근태까지 쓰고(샘플은 2026-04), 월말이 아니면 직전 월까지만 쓴다. 월이 끝나지 않은 근태는 초과근무 합계가 부분 값이라 비교에 맞지 않기 때문이다.

## 누락·중복 처리

| 상황 | 처리 | `데이터점검` 구분 |
|---|---|---|
| 사번 공백/중복(재직자 명단) | 중단 | 중단 |
| 필수 시트·열 없음 | 중단 | 중단 |
| 기준일 불일치 | 중단 | 중단 |
| 입사일이 기준일 이후인 직원 | 분석에서 제외 | 경고 |
| 근태 직원-월 중복 | 마지막 값 사용 | 경고 |
| 근태 월을 해석할 수 없음 / 초과근무가 비었거나 음수·200 초과 | 그 행 제외 | 경고 |
| 최근 3개월/직전 3개월 구간에 근태가 2개월 미만 | 초과근무 신호 판단불가 | 경고 |
| 확정 평가가 2건 미만 | 평가 변화 판단불가 | 경고 |
| 평가 직원-주기 중복 | 마지막 값 사용 | 경고 |
| 계산 가능한 가중치 합 < 50 | 점수·등급 없음(판단불가) | 경고 |
| 재직자 명단에 없는 직원의 행 | 제외 | 경고 |
| 기준일 이후 기록 | 사용 안 함 | 정보(건수) |
| 휴직자 | 분석 포함, 근태 신호 적을 수 있음 | 정보 |

## 날짜·숫자 형식

엑셀 날짜(일련번호)나 `yyyy-MM-dd` 문자열을 읽는다. `pay_month`는 `yyyy-MM` 문자열이나 날짜를 읽는다. 이 이외의 형식은 해석하지 못해 해당 행을 제외하고 경고한다.
